# Product

## Register

product

## Users

Windows users running DeepSeek Harness Web who keep a shared local collection of agent Skills and need to choose which ones are globally visible to DSH.

## Product Purpose

Provide a safe, auditable way to selectively load global DSH Skills from a central directory through Windows Junctions. Success means users can see exactly what is managed, what is external or invalid, and what filesystem change each action will make.

## Brand Personality

Restrained, precise, trustworthy. The interface should feel native to DSH Settings and stay focused on repeated management work.

## Anti-references

Do not resemble a marketplace, installer, or marketing page. Avoid decorative cards, promotional copy, hidden filesystem mutation, bulk-enable mechanics, and visual treatments that make external conflicts look actionable.

## Design Principles

- Make ownership explicit before offering an action.
- Keep irreversible-looking filesystem operations understandable and narrowly scoped.
- Preserve list geometry and context while operations run.
- Prefer familiar settings controls over novel interaction patterns.
- Explain invalid, conflicting, and broken states where they occur.

## Accessibility & Inclusion

Meet WCAG AA contrast, provide complete keyboard and visible focus behavior, respect reduced-motion preferences, and never communicate status through color alone. Chinese and English labels must fit desktop and narrow layouts without clipping.
